# 网页游戏合集

纯前端单文件网页游戏。每个 `.html` 都是完整游戏，**零依赖、零构建**，双击就能玩。

线上地址：**https://xavierwang.top**　（Vercel 项目 `sixgames`，已与本仓库 main 分支关联，push 自动部署；备用地址 sixgames.vercel.app）

| 游戏 | 文件 | 一句话 |
|---|---|---|

## 细胞上行 · 操作

| 按键 | 作用 |
|---|---|
| WASD / 方向键 | 移动 |
| 鼠标 / 左键 | 瞄准，释放溶酶体颗粒 |
| 空格 / 鼠标右键 | 吞噬：范围伤害 + 回血 + 压低感染度（6.2s 冷却） |
| Q | 趋化信号：召唤中性粒细胞 / 巨噬细胞（13s 冷却） |
| Shift | 冲刺 |
| P / Esc · M | 暂停 · 静音 |

玩法：病毒不会追你，它们全力往大脑逃。**脱离你 1500px 就算扩散**，感染度上涨；感染度满 100% 判负。
击杀（-0.9）与吞噬（-2.8）能把感染度压回去。病毒每 14–17 秒进化一级，共 5 级；感染度越高，病毒生命与伤害也越强。
抵达血脑屏障后，先击碎病毒母体的三处复制核，再摧毁核心。

## 本地运行

直接双击 `index.html`；或用任意静态服务器：

```bash
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

## 技术说明

- 单文件 HTML + Canvas 2D，无框架、无构建步骤、无外部图片资源。
- 所有美术由代码绘制（`drawFar` / `drawGun` / `drawWeaponBlade` 等）。
- 弹道为自研简化物理：每颗子弹带 `g/drag/bounce`，用扫掠线段命中检测防高速穿透。
- 两款"上行"的平衡都用无头机器人实测：
  - 病毒上行：会拉扯的机器人在三种毒株下通关率 5/8–8/8，单局 100–130 秒。
  - 细胞上行：完美瞄准机器人三种细胞各 6/6，带瞄准误差的普通玩家模型约 14/15，单局 95–110 秒；只冲不打必然被感染度压死。
