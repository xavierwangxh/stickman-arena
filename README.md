# 网页游戏合集

纯前端单文件网页游戏。每个 `.html` 都是完整游戏，**零依赖、零构建**，双击就能玩。

线上地址：**https://sixgames.vercel.app**　（Vercel 项目 `sixgames`，已与本仓库 main 分支关联，push 自动部署）

## 游戏列表

| 游戏 | 文件 | 一句话 |
|---|---|---|
| 病毒上行 | `games/virus-ascension.html` | 从脚底伤口入侵到大脑，15 种突变对抗白细胞、巨噬细胞与血脑屏障 |
| 火柴人大战 | `games/stickman-arena.html` | 16 把冷兵器与枪械、18 关战役 + 6 场 BOSS、4 兵种、生化与无尽模式、弹道物理、护甲系统 |
| 火柴人枪枪大战 | `games/stickman-shooter.html` | 横版射击 + 剧情 + 多武器 |
| 坦克大战 | `games/tank-battle.html` | 经典保卫基地，5 种玩家坦克 |
| 赵云与阿斗 | `games/zhaoyun-realtime.html` | 长坂坡实时动作版 |
| 赵云与阿斗 · 文字版 | `games/zhaoyun-text.html` | 回合制文字版 |

首页 `index.html` 是合集入口，链接到上面六个游戏。

## 病毒上行 · 操作

| 按键 | 作用 |
|---|---|
| WASD / 方向键 | 移动 |
| 鼠标 | 瞄准，左键喷刺突 |
| Shift / 空格 | 冲刺 |
| P / Esc | 暂停 |
| M | 静音 |

玩法：感染红细胞与免疫细胞拿基因片段，升级三选一突变（15 种，可叠加 2–3 层）；击碎血脑屏障三处紧密连接后冲进神经元核。

## 本地运行

直接双击 `index.html`；或用任意静态服务器：

```bash
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

## 技术说明

- 单文件 HTML + Canvas 2D，无框架、无构建步骤、无外部图片资源。
- 所有美术由代码绘制（`drawFar` / `drawGun` / `drawWeaponBlade` 等）。
- 弹道为自研简化物理：每颗子弹带 `g/drag/bounce`，用扫掠线段命中检测防高速穿透。
- 病毒上行的平衡用无头机器人实测：完美瞄准 + 会拉扯的机器人在三种毒株下通关率 5/8–8/8，单局 100–130 秒。
