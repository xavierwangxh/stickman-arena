# 火柴人大战 · 网页游戏合集

纯前端单文件网页游戏，零依赖、零构建，双击 `index.html` 就能玩。

## 线上地址

- 主游戏（火柴人大战）：`https://<你的域名>/`
- 其他游戏：见 `games/` 目录

## 游戏列表

| 游戏 | 文件 | 说明 |
|---|---|---|
| 火柴人大战 | `index.html` | 16 把冷兵器与枪械、18 关战役 + 6 场 BOSS、4 个兵种、生化模式、无尽模式、弹道物理、护甲系统 |
| 火柴人枪枪大战 | `games/火柴人枪枪大战-试玩版.html` | 横版射击 + 剧情 + 多武器 |
| 坦克大战 | `games/坦克大战-试玩版.html` | 经典保卫基地，5 种玩家坦克 |
| 赵云与阿斗 | `games/赵云与阿斗-试玩版.html` | 实时可玩版 |
| 赵云与阿斗（文字版） | `games/赵云与阿斗-文字版.html` | 文字回合制 |

## 火柴人大战操作

| 按键 | 作用 |
|---|---|
| A / D | 移动 |
| W | 跳跃（二段） |
| 鼠标 | 瞄准，左键攻击 |
| 1-0 / Z X C V B N | 换武器 |
| 滚轮 / Q E | 循环武器 |
| R | 换弹 |
| Shift | 闪避 |
| G | 手雷 |
| P / M / F | 暂停 / 静音 / 弹道物理开关 |
| Tab | 切换模式（战役 / 生化 / 无尽） |

## 玩法要点

- **三种模式**：战役（18 关有剧情）、生化（守住 8 波感染潮）、无尽（程序化无限关卡）。
- **四个兵种**：突击（机动）、狙击（爆头）、重装（减伤 + 最厚护甲）、工程（弹药 + 两名友军）。
- **16 把武器**：含弹道物理——下坠、跳弹、后坐力、爆头倍率，打远距离要抬枪补偿。
- **护甲**：挨打先掉甲、甲碎才掉血；近战绕 35%、爆炸绕 40% 的护甲，所以不能只靠甲站着硬吃。

## 本地运行

直接双击 `index.html`，或用任意静态服务器：

```bash
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

## 技术说明

- 单文件 HTML + Canvas 2D，无框架、无构建步骤。
- 所有美术为代码绘制（`drawFar` / `drawGun` / `drawWeaponBlade` 等），无外部图片资源。
- 弹道为自研简化物理：每颗子弹带 `g/drag/bounce`，用扫掠线段命中检测防高速穿透。
